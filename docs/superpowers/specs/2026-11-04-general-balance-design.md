# 武将平衡设计（2026-11-04）

## 背景
- 现有 [BALANCE.md](https://github.com/zcbnu/sanguo-duel/blob/main/BALANCE.md) 已记录第一批模拟梯队与第二批体力微调（华雄仍偏弱）。
- 牌库 v2（20 新牌 + 重平衡）上线后，尚未对 96 将全库重跑胜率，旧表可能过时。

## 目标
- 全库 96 武将重跑 AI 模拟后，**尽量把胜率压进 40–60%**。
- 手段：**先改技能，再动体力**；不改牌库、不改全局规则（护体、兵疲、手牌上限=体力+1）。

## 流程（方案 A）
1. 用现有 `tools/sim.js` 对 96 将全库跑一轮（每对阵 ≥8 局，与 BALANCE.md 一致或更高），写出新胜率表（更新 `tools/sim-result.json`）。
2. 名单：胜率 >60% 待削弱，<40% 待加强；40–60% 不动。
3. 每轮只改名单内武将：优先改技能（加代价 / 补收益），仍偏再动体力 ±1。
4. 改完重跑；重复直到尽量全进 40–60%（允许少数依赖读牌/时机的将因 AI 偏差留在边缘，并在 BALANCE.md 注明）。
5. 更新 `BALANCE.md` 梯队与改动记录，合并并发布 GitHub Pages。

## 改技能规则
- **待削弱（原 T1）**：加条件、降收益、限次数，或把选择权交给对手；不删核心身份感。
- **待加强（原 T3）**：补摸牌/转化/反馈，或略放宽触发；可小幅加新效果，不整技换人。
- 只借鉴机制模式，不照搬三国杀原名/原文。
- 体力保持 3–5；每人至少保留一个有意义选择。
- 教程/残局若依赖被改技能，同步修通关（如 `data/modes.js`）。
- 每轮改动写入 BALANCE.md「主要改动」。

## 验收与交付
- **成功标准**：重跑后 ≥90% 武将胜率在 40–60%；`errors=0`、一回合秒杀=0；中位回合仍大致每人 6–12。
- **交付物**：`data/generals.js` + 技能实现改动、更新后的 `BALANCE.md` 与 `tools/sim-result.json`、必要时修 modes；开 PR 合并并发布 Pages。
- **已知限制**：AI 胜率低估读牌/时机将，边缘个案在文档标明即可。

## 范围外
- 不改牌库比例与新卡。
- 不改护体/兵疲等共享规则（除非验收失败且用户另行批准）。
- 本规格仅描述设计；实现另开计划后落地。
